Q. Develop a Python program to maintain student attendance and calculate the total number of present and absent students.


Algorithm:

Display the student's name, section and roll number.
Enter attendance as P (Present) or A (Absent).
Check whether the entered attendance is valid.
If the input is invalid, ask the user to enter P or A again.
If attendance is P:
Append "Present" to the student list.
Increment the present count.
Otherwise:
Append "Absent" to the student list.
Increment the absent count.
Repeat the process for all students.
Display the final attendance report.
Display the total number of students, present students and absent students.
Stop the program.
